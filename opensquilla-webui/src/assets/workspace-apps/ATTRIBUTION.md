# Workspace application artwork

These files are bundled locally to identify the applications in the file opener.
Names and marks remain the property of their respective owners. The SVG files
are copied without geometry changes. Cursor, Windsurf and Zed are rendered as
alpha masks so their original silhouettes remain visible in both themes.
