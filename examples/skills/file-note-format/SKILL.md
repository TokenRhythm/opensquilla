# Format a note

Read `{baseDir}/references/format-guide.txt` and `note.txt` with `read_file`.
Format the existing facts according to the guide and write `formatted.txt`
with `write_file`. Return a short handoff naming `formatted.txt`. Preserve the
facts and use only the workspace for generated files.
