# Edit an announcement

Read `{baseDir}/references/style-guide.txt` with the file-reading tool. Compare
the supplied draft against the original request. Preserve the user's language
and factual details; remove unsupported claims and repetitive phrasing.

Return the edited announcement only. Do not add a review report, publish the
announcement, call external services, or write files.
