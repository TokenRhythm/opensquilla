# OpenSquilla 0.5.5

## Overview

C5 multi-model fusion, more reliable tasks, persistent workspaces, Tencent
SkillHub, and signed Windows installers.

## ✨ What's Improved

- **C5 fusion:** four models draft candidates and a tool-capable model combines
  them. See the [evaluation summary](https://github.com/TokenRhythm/opensquilla/blob/v0.5.5/docs/features/MULTI-MODEL-FUSION-C5-RELEASE-NOTE.md).
- **Chats, Plans, and Goals:** better reconnect recovery, saved attachment
  drafts, editable task progress, and clearer pause, resume, and cancellation.
- **Workspaces and documents:** persistent task files, local HTML previews,
  inline file actions, and bounded document reading and editing.
- **Models and Skills:** editable model limits, provider-aware Router presets,
  Tencent SkillHub, and interactive terminal input for managed commands.
- **Desktop:** faster startup, stronger Gateway recovery, signed Windows
  installers, and anonymous stability telemetry.

See the [full changelog](https://github.com/TokenRhythm/opensquilla/blob/v0.5.5/CHANGELOG.md#055---2026-09-23).

## Upgrading from 0.5.4

Quit Desktop and the Gateway, back up the active profile, and install over the
existing installation. Configuration, chats, Agents, memory, and schedules stay
in that profile; no manual data transfer is required. Supported database migrations
run automatically. Upgrade clients and Gateway together.

- **Router:** the one-time version 2 configuration migration replaces C0–C3
  text tiers for an OpenRouter or TokenRhythm primary, including custom or
  mixed tiers and configurations with Router disabled. A
  `config.toml.backup.<timestamp>` is saved first. Reapply custom tiers in
  settings after upgrading; those subsequent edits remain intact. See the
  [Router guide](https://github.com/TokenRhythm/opensquilla/blob/v0.5.5/docs/features/squilla-router.md).
- Goal Token budgets and foreground/background execution settings are retired.
  History and usage remain. Automatic continuation needs a live authenticated,
  subscribed client; explicitly resume Goals after a Gateway restart.
- Retired bundled Skills and `create_csv`, `create_xlsx`, `create_pptx`, and
  `create_pdf_report` should be replaced with current Skills and generic tools.
  Personal Skills remain. Ordinary channel authoring is unavailable on Windows.
- Workspace `BOOTSTRAP.md`, `HEARTBEAT.md`, and `TOOLS.md` integration is retired.
  Files remain; move required instructions into `AGENTS.md`. From 0.5.3 or
  earlier, reinstall needed optional Runtime Packs through Sandbox settings.

> [!IMPORTANT]
> Windows users coming from RC3 or an older pre-Preview-4 build must not
> uninstall that build first: older uninstallers may delete
> `%APPDATA%\OpenSquilla`. Back it up, then install 0.5.5 in place.

On macOS, replace the app in Applications, eject the DMG, and open that copy.
For CLI installation, see the [quickstart](https://github.com/TokenRhythm/opensquilla/blob/v0.5.5/docs/quickstart.md).
Published artifacts include the Web UI; source builds require Node.js 22.12+.
