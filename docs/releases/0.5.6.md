# OpenSquilla 0.5.6

## Overview

Core bug fixes and Browser Use (Beta).

## ✨ What's Improved

- **Core reliability:** fixes for Gateway connections, task recovery,
  Stop/Queue/Steer, Goal continuation, provider streams, and conversation history.
- **Local files:** fixes file selections that appeared to do nothing. Selected
  local references show short filenames before and after sending, including
  after reload or editing; full paths remain available to the Agent and copying.
- **Browser Use (Beta):** browse and interact with pages through Desktop's
  built-in browser tools and Workbench. This is an early Beta, not a replacement
  for your system browser; standalone WebUI does not provide the Desktop browser.

See the [full changelog](https://github.com/TokenRhythm/opensquilla/blob/v0.5.6/CHANGELOG.md#056---2026-09-30).

## Upgrading from 0.5.5

Quit Desktop and the Gateway, back up the active profile, and install over the
existing installation. Configuration, chats, Agents, memory, and schedules stay
in that profile; no manual data transfer is required. Supported database migrations
run automatically. Upgrade clients and Gateway together.

The retired background-music player and experimental router self-learning are
removed. Personal music and historical training files remain on disk. Existing
Router configuration and Dream memory consolidation keep their normal roles.
Local-path display changes do not upload files or grant additional file access.

<details>
<summary>Upgrading from 0.5.4 or earlier</summary>

- The one-time version 2 Router configuration migration replaces C0–C3 text
  tiers for an OpenRouter or TokenRhythm primary and backs up the old config.
  Reapply custom tiers after that migration; subsequent edits remain intact.
- Goal Token budgets and foreground/background execution settings are retired.
  History and usage remain; explicitly resume Goals after a Gateway restart.
- Retired bundled Skills and format-specific authoring tools should be replaced
  with current Skills and generic tools. Ordinary channel authoring is unavailable on Windows.
- Workspace `BOOTSTRAP.md`, `HEARTBEAT.md`, and `TOOLS.md` integration is retired.
  Files remain; move required instructions into `AGENTS.md`. From 0.5.3 or earlier,
  reinstall needed optional Runtime Packs through Sandbox settings.

> [!IMPORTANT]
> Windows users coming from RC3 or an older pre-Preview-4 build must not
> uninstall that build first: older uninstallers may delete
> `%APPDATA%\OpenSquilla`. Back it up, then install 0.5.6 in place.

</details>

On macOS, replace the app in Applications, eject the DMG, and open that copy.
Published artifacts include the Web UI; source builds require Node.js 22.12+.
